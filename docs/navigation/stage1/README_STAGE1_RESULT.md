## 实测效果

| 弯道 | 实际最低速度 m/s | 弯道通过时间 s |
| --- | --- | --- |
| 1 | 0.294 | 3.743 |
| 2 | 0.292 | 3.785 |

| 4 | 0.296 | 3.650 |

相较当天旧 0.30 弯道基线，最低实速从约 0.10 提高到约 0.29–0.30 m/s，单弯通过时间从约 8 s 降到约 3.7 s。直线反馈峰值约 0.966 m/s。该轮使能期间 4251 帧控制状态均为 `TRACKING`，用户反馈效果明显改善。

第一阶段的成果范围是空场整圈的直线提速与转弯衔接。最低弯速 0.50 m/s 尚未达到。定位跳变、右侧障碍物接触及动态障碍弯道停车作为后续问题保留，未写作已通过。
