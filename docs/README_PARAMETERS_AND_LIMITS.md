## 尚未解决

- 最低弯速 0.50 m/s 未达到；弯中跟踪误差仍会触发 0.35 m/s 恢复限速。
- 后续带障碍物测试出现 AMCL 全局修正与局部里程计连续性不一致、`position_jump`、绿黄轨迹断开及停顿。原 `likelihood_field` 配置也有对应问题，回到本阶段不能视为已修复。
- 后续试验确认起点第一个黑色泡沫纸箱接触车身右侧。稀疏点序列 2、2、1 未达 3 点门槛，实际跟踪偏差也侵蚀了规划净距，须继续核查轮廓与探测。
- 动态障碍弯道持续停车的直接请求涉及规划超时和空路径，不能统一归因于 Safety；禁止把关闭 Safety 作为本分支复现步骤。

后续定位连续性、稀疏障碍保护、规划超时和跟踪改进从本阶段另开候选并单独验证。

## 可复用经验

1. 同时核对本终端导入路径和线上节点配置，避免 F 的新目录检查了旧 E 的节点。
2. 以成功冻结源码为起点，每轮只推进一个明确目标，记录参数与实测；保留旧运行目录。
3. 平顺接缝改善弯直衔接；单独上调速度或曲率变化率并不能保证反馈最低速度提高。
4. 故障按定位、规划、控制、Safety 的时间线定位直接原因，轨迹图形和单个状态不足以定因。
